# GodMod
GodMod is multi-modal plugin for Minecraft bedrock worlds, realms and dedicated servers 

# How to use?
1 - Enable "Beta API's" in Experiments before create/join your world. \n 
2 - Create a tickingarea and use there "/function dbsetup \n
3 - Type "!help" to chat for look commands (prefix is: !) \n
4 - Select compass or paper and right click it for look UI features \n
